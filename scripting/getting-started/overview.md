# Getting Started

These are independent introductions to the places where ERP.net supports scripts. Each starts in a different product feature; they are not steps in one sequence.

- [User business rules](user-business-rules.md) run a script when a configured business-rule event occurs.
- [Calculated attributes](calculated-attributes.md) evaluate a script to produce an attribute value.
- [ExecuteScript](execute-script.md) accepts one-off JavaScript through the Domain API.
- [Managed scripts](managed-scripts.md) store a callable definition in `Systems.Core.Script` with declared inputs and results.

For reusable API operations that are not tied to one feature, continue with [Scripting APIs](../apis.md) and [Common patterns](../examples/common-patterns.md). The [execution-context reference](../execution-context.md) explains which globals and results are available in each feature.
