# Examples

The examples are organized by what can be reused and by the feature that hosts a complete script.

- [Common patterns](common-patterns.md) covers special Domain types, `Action`, and files. The [basic Domain examples](basic-domain.md) walk through retrieval, creation, updates, and deletion; the [advanced Domain examples](advanced-domain.md) show object initializers and the supported filter forms in detail.
- [User business rules](user-business-rules.md) contains complete event-driven scripts using `subject`.
- [Calculated attributes](calculated-attributes.md) contains calculations that return an attribute value.
- [ExecuteScript](execute-script.md) contains complete freeform Domain API requests.
- [Managed scripts](../examples.md) contains `ScriptText`, parameter schemas, requests, and responses.

Do not copy a script body from one feature into another without checking its [execution context](../execution-context.md) and result contract.
